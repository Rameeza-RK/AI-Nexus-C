# AI-Nexus-C
An AI powered C project featuring six interactive modules for gaming,problem solving,creative security and smart utilities integrating basic AI functionalities and data structures like queues


AI Nexus C – Smart Multi-Feature Toolbox
AI Nexus C is a menu-driven project developed using the C programming language. It includes colorful console output and six main modules, each offering different features and activities.
Main Features
1. Game Zone: Memory Match, Tic-Tac-Toe, and other game activities.
2. Problem Solving Lab: Calculator and Logical Lab.
3. Creative Studio: ASCII Art, Checkerboard Designer, Wave & Zigzag Art, Spiral Art, Random Art Generator, and AI Design Challenge.
4. Security Hub: Caesar Cipher and Password Strength Checker.
5. Smart System: Banking System and Stock Market.
6. Daily App: Date and Time Calendar.
Additional Features
- Multiple options in each module.
- Easy, Medium, and Hard difficulty levels where applicable.
- Colorful console interface.
- Easy navigation through numbered menus.
- Red-colored option to return to the main toolbox (0).
Purpose: To practice C programming concepts, improve logical thinking, and explore different programming features in one interactive project.
